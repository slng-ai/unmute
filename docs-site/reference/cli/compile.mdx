```
$ unmute compile --help
Compile a v1 agent package to its resolved target artifacts.

Usage:
  unmute compile <package-dir> [flags]

Flags:
  -h, --help             help for compile
      --target strings   target instance name (repeatable; default: all)
```

## Usage

```sh
unmute compile examples/simple-prompt --target pipecat
```

Every file written is printed:

```
generated examples/simple-prompt/build/pipecat/.dockerignore
generated examples/simple-prompt/build/pipecat/.env.example
generated examples/simple-prompt/build/pipecat/Dockerfile
generated examples/simple-prompt/build/pipecat/README.md
generated examples/simple-prompt/build/pipecat/bot.py
generated examples/simple-prompt/build/pipecat/compile-report.json
generated examples/simple-prompt/build/pipecat/compose.dev.yaml
generated examples/simple-prompt/build/pipecat/pcc-deploy.toml
generated examples/simple-prompt/build/pipecat/pyproject.toml
generated examples/simple-prompt/build/pipecat/tools/__init__.py
...
```

Output goes to `<package>/build/<target-instance-name>/`. With no `--target`,
every declared target is compiled. `--target` is repeatable.

## The report

After the files, the compiler prints what it decided. Every line is prefixed
with the target instance name.

**Bindings.** What each model role resolved to, and the honest note that the
model string is not checked:

```
pipecat: binding listen provider=slng model=slng/deepgram/nova:3-en (forwarded as-is, not validated)
pipecat: binding turn provider=local model=silero (forwarded as-is, not validated)
pipecat: binding speak.voice provider=slng model=slng/deepgram/aura:2-en voice=aura-2-thalia-en (forwarded as-is, not validated)
pipecat: binding reason.reasoning provider=openai model=gpt-5.6-luna (forwarded as-is, not validated)
pipecat:   param temperature=0.2
```

**Sizing.** Your `capacity:` block turned into numbers, tagged with the
assumption they came from:

```
pipecat: sizing workers=10 [unbenchmarked] (2026-07-15 conservative 1 session per worker/GPU; channels=realtime_audio)
pipecat: sizing provider_concurrency_quota.realtime_audio=5 [unbenchmarked] (2026-07-15 conservative 1 session per worker/GPU; channels=realtime_audio)
```

**Telephony.** Present only for a target with a phone route: the resolved
route, the endpoints, every required environment variable, and an evidence line
per capability:

```
livekit: telephony route provider=livekit transport=sip carrier=twilio coordination=shared admission=livekit_dispatch
livekit: telephony required env SIP_TRUNK_HOSTNAME
livekit: telephony evidence inbound=provisional docs=https://docs.livekit.io/telephony/start/providers/twilio/ verified=2026-08-12 smoke=false
```

`provisional` means implemented and compiling, with no credentialed test in CI.
`smoke=false` says the same thing in the machine readable half.

The same information is written to `build/<target>/compile-report.json`.

## Warnings

Warnings print first, on standard error, and do not change the exit code:

```
warning: livekit: LiveKit turn placement is a preference
```

## Compiling is safe to repeat

`build/` is output. Compile as often as you like; never edit inside it.
