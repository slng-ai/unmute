Unmute is a command line compiler for voice agents. You write one package of
YAML and Markdown. Unmute turns it into a real Python project for the
orchestrator you picked, and that project is yours to run and deploy.

## The problem

A voice agent is a small idea buried in a lot of plumbing. Speech in, a model
that thinks, speech out, a way to end the call, a way to hand the caller to a
person. Every orchestrator asks you to write that plumbing again, in its own
shape.

So teams end up here:

- The prompt, the tools, and the phone number live in the same file as the
  session setup, the audio pipeline, and the retry logic.
- Changing the voice means reading orchestrator code.
- Trying a second orchestrator means rewriting the agent.
- Nobody can answer "what does this agent actually do" without reading Python.

## What Unmute does

Unmute splits the agent from the runtime.

You describe the agent once: who it is, which models it uses, which tools it
can call, how it hands work to another agent, what happens on a phone call.
That description is the package. It has no orchestrator code in it.

Then you pick a target. Unmute compiles the package into a native project for
that target: a Pipecat bot or a LiveKit Agents worker, with a Dockerfile, a
`.env.example`, and a runbook. The generated project has no Unmute dependency
at runtime. Unmute is not in the call path.

## What a spec looks like

An Unmute package keeps the portable agent in `agent.yaml`, its prompt in a
Markdown file, and runtime choices in `targets.yaml`. The guided example shows
the complete files, then explains each block where you first need it.

## Who it is for

- Teams who ship voice agents and are tired of maintaining orchestrator code.
- Teams who want to compare Pipecat and LiveKit Agents without writing the
  agent twice.
- Anyone who wants the agent's behavior reviewable in a pull request, in files
  a non-Python reader can follow.

Unmute is not a hosted platform and not a runtime. It compiles ahead of time,
hands you the project, and gets out of the way.
