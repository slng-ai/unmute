Unmute is one static binary. Install it with your package manager, download it,
or build it from a clone.

## Pick a way

| How | Command | Works on |
|---|---|---|
| Homebrew | `brew install slng-ai/tap/unmute` | macOS only |
| winget | `winget install slng.unmute` | Windows |
| Go | `go install github.com/slng-ai/unmute@latest` | anywhere with Go 1.24 or newer |
| Archive | download from the [releases page](https://github.com/slng-ai/unmute/releases) | macOS, Linux, Windows, on amd64 and arm64 |

Homebrew is macOS only because Homebrew on Linux has no casks. On Linux, use
`go install` or the archive.

Each archive holds the binary, the LICENSE and the README. Every release also
carries a `checksums.txt`, its signature, and one SBOM per archive, so you can
check what you downloaded before you run it.

<Note>
  While the repository is private, only the archive and a clone work. Homebrew,
  winget and `go install` all fetch over public URLs.
</Note>

## What you need to run an agent

| Tool | Needed for | Check |
|---|---|---|
| Docker with Compose | `unmute dev` in the browser | `docker compose version` |
| `uv` | `unmute dev --console` in the terminal | `uv --version` |
| Go 1.24 or newer | `go install`, or building from a clone | `go version` |

Docker and `uv` are only needed when you run an agent. You can write, validate,
and compile a package without either.

## Build from a clone

The contributor path, and the one to take if you want to change the CLI itself.

<Steps>
  <Step title="Clone the repository">
    ```sh
    git clone https://github.com/slng-ai/unmute.git
    cd unmute
    ```
  </Step>
  <Step title="Build">
    ```sh
    make build
    ```

    That writes `bin/unmute`. The direct equivalent is
    `CGO_ENABLED=0 go build -o bin/unmute .`, and the version string is stamped
    in at link time.
  </Step>
  <Step title="Check it">
    ```sh
    bin/unmute --version
    ```

    ```
    unmute version 1.2.0 (3a9f2c1 2026-08-14T10:11:12Z)
    ```

    The three parts are the version, the commit it was built from, and that
    commit's date. You will see your own build's values, not these. A plain
    `go build` with no link-time stamping prints `unmute version dev`.
  </Step>
</Steps>

## Put it on your PATH

```sh
make install
```

That runs `go install`, which puts `unmute` in your Go bin directory (usually
`~/go/bin`). Add that directory to your PATH and you can run `unmute` from
anywhere. The rest of these pages write `unmute`; if you skipped this step,
read that as `bin/unmute` from the repository root.

A package manager install is already on your PATH.

## Shell completion

The binary generates its own completion script:

```sh
unmute completion zsh
```

`bash`, `fish`, and `powershell` work the same way. Each subcommand's help
explains where to put the output on your system:

```sh
unmute completion zsh --help
```
