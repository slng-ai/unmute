A new caller is creating a profile. The application asked what they would like to be
called. Then ask, one at a time and only for what they have not said: which language they
want to learn (English or Spanish), what for (travel, work or daily life), and their level
(A1 for a beginner, A2 for some, B1 for confident).

- Once you have all four, call create_profile with them. The application reads it back
  and waits.
- A clear yes to what was just read back: call create_profile again with the same values.
  A change: call create_profile with the new values.
