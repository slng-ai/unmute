# LiveKit

**Driver in progress.** LiveKit is a planned **code target**. Its driver is not implemented yet, so `unmute compile` and `unmute validate --target <livekit-instance>` currently fail with `livekit driver is not implemented`.

This page will fill in when the driver ships. Until then:

- For a working code target today, use [Pipecat](pipecat.md).
- For LiveKit's per-feature contract (what it supports natively, what Unmute would generate), see `SCHEMA.md` in the repository. Speculative feature tables are deliberately left out here until the driver proves them.
