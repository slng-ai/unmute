# livekit — generated LiveKit Agents project

Generated by `unmute compile` (LiveKit driver). Model routes, prompts, agents,
tasks, and tools come from the source package. Entry agent: `Assistant`.

## Run

Install the generated dependencies, copy the environment template, and start
the LiveKit development worker.

```sh
uv sync                       # or: pip install -e .
cp .env.example .env          # then fill in the selected provider values
uv run agent.py console       # local terminal session
uv run agent.py dev           # LiveKit development worker
```

## Deploy

Deployment is self-hosted: the worker connects out to a LiveKit Server you
run and needs no inbound ports. Build the generated `Dockerfile` into an
image, set `LIVEKIT_URL`, `LIVEKIT_API_KEY`, and `LIVEKIT_API_SECRET` to your
server's values plus the provider keys from `.env.example`, then start the
worker:

```sh
python agent.py start
```

See `docs/DEPLOYMENT.md` in the Unmute repository for the full self-hosted
setup: server, Redis, firewall ports, sizing, and scaling.

Compatibility note: the project also runs on LiveKit Cloud with the `lk` CLI
(`lk agent create`), but that is not the supported path.
Do not edit this project by hand — it is regenerated from the agent spec.
Change the spec and recompile.
